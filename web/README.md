# Mobile Web Game

The primary target is iPhone/iPad Safari and modern mobile browsers.

## Run
Serve the repository root with any static web server and open /web/ in a browser. GitHub Pages can publish the web directory through a deployment workflow.

## Input
The game uses Pointer Events for the virtual joystick and action buttons. Pointer Events provide a unified input model for touch, mouse, and pen and support simultaneous pointers.

## Design
Mobile-first, landscape, no proprietary game assets or code. Core gameplay is intentionally modularized for later improvements to AI, tactics, animation, camera, player attributes, saves, and online play.
